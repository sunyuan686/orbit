# 随想 / 短动态编辑与发布功能设计稿 (Thought & Microblog Spec)

> 架构归属：产品能力方案 · 归档于 `docs/specs/thought-compose.md`

## 1. 背景与目标

目前 Orbit 的富文本编辑器采用沉浸式文档大画布模式，适合撰写长日记、长文章或深度总结。但在日常使用中，存在大量“**随手记录一两句话 + 几张生活照片**”的轻量随想（Thought / Microblog）场景。

直接使用长文章编辑器创作短随想会导致：
1. **心理负担重**：大画布和标题栏让用户觉得必须“写成文章”。
2. **短文本排版割裂**：在“今天天气真好”两字下方直接放入几张巨大尺寸的图片，会割裂短内容的连贯阅读体验。

**目标**：借鉴 Jant 的双态编辑体验，建立 **短随想 (`Note`)** 与 **长文章 (`Article`)** 架构解耦，提供极简、顺畅的短动态发布体验。

---

## 2. 核心交互方案

### 2.1 轻量短随想弹窗 (`Note` 模式)
- **界面样式**：
  - 取消标题栏，默认聚焦于纯粹的输入文本框（Placeholder: *"记录这一刻的随想…"*）。
  - **图片上传区（媒体卡片队列）**：上传的图片不插在文字中间，而是平铺展示在编辑框下方的**小缩略图卡片区**。
  - **缩略图微交互**：
    - 右上角带 `×` 一键移除图标。
    - 下方带 `+ ALT` 按钮，点击弹窗输入无障碍描述/关键词。
- **发布态渲染**：
  - 在时间线/动态流中，自动渲染为 **Note Card + Media Gallery 网格/九宫格**（上文下图，1~4 图响应式优雅拼图）。

### 2.2 全屏长文章画布 (`Article` 模式)
- **切换入口**：
  - 仅在桌面大屏（宽度 $> 700\text{px}$）下，弹窗右上角提供**全屏展开图标 `[ ⛶ ]`**。
  - 点击后，编辑态**零延迟无缝转换**为全屏大文章画布：
    - 自动浮现文章标题栏 (`Title`)。
    - 底部附件图片自动转为正文行内大图 (`Inline Image`)。
    - 展开完整斜杠菜单 (`/`)、选区气泡工具栏与侧边栏。

### 2.3 移动端响应式策略 (Mobile Adaptive)
- **移动端 (`< 700px`) 策略**：
  - 隐藏全屏展开按钮，移动端默认且仅保留轻量 `Note` 创作框。
  - 适配软键盘弹起高度，避免复杂工具栏遮挡，实现零负担随时记录。

## 3. 数据结构设计

```ts
export interface PostThoughtPayload {
  type: "note" | "article";
  title?: string;
  content: string; // HTML / TipTap JSON
  mediaAttachments?: Array<{
    url: string;
    alt?: string;
    width?: number;
    height?: number;
    blurhash?: string;
  }>;
  collectionId?: string;
}
```

## 4. 实施阶段计划

1. **Phase 1: 组件库 MediaGallery 媒体九宫格卡片开发**
   - 类似 Jant 开发 1~4 图拼图组件，用于支持随想流上文下图展态。
2. **Phase 2: 轻量发帖弹窗 (Compose Dialog) 与图片附件队列**
   - 增加缩略图预览队列与 `+ ALT` 输入功能。
3. **Phase 3: 桌面端全屏无缝平滑状态迁移 (Fullscreen Handoff)**
   - 实现随想弹窗与全屏大文章编辑器的两态转换与草稿同步。
