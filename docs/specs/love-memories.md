# 恋爱记忆（星图 + 图鉴）

> 把已有内容织成「我们的回忆」：点点滴滴都是成就，好玩可爱向。  
> 进度见 [ROADMAP.md](../../ROADMAP.md)（Phase E · 恋爱记忆星图 / 图鉴 / 里程碑）。  
> 数据来自 `entry`、`asset`、空间档案纪念日；不新增写作类型。

---

## 目标

回答「我们在一起积累了什么」，而不是「谁得了多少分」。

- **星图**：整体感——每段回忆是一颗星，远看光晕，近看可点进原文
- **图鉴**：收藏感——同一批回忆按册浏览，翻卡片、集徽章
- **原则**：回忆即成就；不做积分商城、扣分、双人排行、每日任务

气质：**俏皮、可爱、有小庆祝**（点亮动效、集齐星座、里程碑文案）。

---

## 非目标

| 不做 | 理由 |
|------|------|
| 爱情小店 / 兑换券 | 与产品方向不符 |
| 可消耗积分、扣分 | 易变关系 KPI / 指责工具 |
| 个人排行榜、段位 | 双人空间不宜竞争叙事 |
| 每日签到、任务清单 | 与「无压力记录」冲突 |
| 用户单独维护「游戏条目」 | 成就应来自真实内容，不增加写作负担 |

---

## 核心概念

### 记忆节点（Memory Node）

从现有数据**只读聚合**出的最小单位，一颗星 / 一张图鉴卡对应一个节点。

| 来源 | 节点粒度 | 说明 |
|------|----------|------|
| `entry`（diary / timeline / message / letter） | 一篇 | 回信树每封主信 / 回信各算一节（待定） |
| `gallery` `asset` | 一张未单独挂 entry 的图 | 可选：与 entry 重复时合并为一节点 |
| 空间档案纪念日 | 锚点节点 | 相识日等，无正文也可亮星 |
| `memo` | 不计入 | 活文档，语义与「回忆瞬间」不一致（对齐 activity） |

节点字段（逻辑模型，实现可派生不落库或部分物化）：

- `id`、`sourceType`、`sourceId`、`occurredAt`（`entry_date` 或资产时间）
- `title`、`snippet`、`coverImage`（列表 / 卡片用）
- `authors`、`contentType`
- `weight`：视觉层次（有图、长文、信件略亮），**不是道德评分**
- `milestoneId?`：若命中系统里程碑规则

### 里程碑（Milestone）

系统自动识别的「高光时刻」，在星图上更亮、在图鉴「里程碑」册里有大卡。

示例规则（MVP 硬编码，二期可扩展）：

- 关系：在一起第 7 / 30 / 100 / 365 / 1000 天
- 创作：第一封信、第 10 / 50 / 100 篇 diary、第一封回信
- 节奏：streak 当前达 7 / 30 / 100 天（读 activity）
- 空间：相册第 50 / 100 张图

触发：节点创建或定时任务扫描；**只加分亮、不通知轰炸**（可选站内轻提示，默认关）。

### 星座（Constellation）— 二期

满足隐藏组合时，星图连线 + 解锁彩蛋文案。例：「三次旅行」「回信往来满 10 次」。

与 ROADMAP「彩蛋惊喜」联动；MVP 不做。

## 星图

### 产品行为

| 项 | 说明 |
|----|------|
| 路由 | `/memories` 或 `/constellation`（待定） |
| 布局 | 双人轨道隐喻：两颗行星 + 周围星群；时间轴可横向滑动 |
| 交互 | 缩放：远观密度光晕 → 近观单星；点击跳转原文 / 相册 |
| 动效 | 新内容后首次进入：新星点亮 + 短动画；`prefers-reduced-motion` 降级 |
| 文案 | 「我们一起记下了 N 个瞬间」；避免「得分」「排名」 |

### 视觉层次

- 类型：diary / letter / message / timeline / photo 不同形状或色
- 亮度：`weight` 三档即可（MVP）
- 里程碑：大号星 / 光晕 / 专属图标

### 与 activity 关系

- 热力图 = 时间维度的「有多密」；星图 = 空间维度的「有哪些」
- 互相链接：activity 页入口 → 星图；星图时间带可跳 activity

## 图鉴

### 产品行为

| 项 | 说明 |
|----|------|
| 路由 | `/memories/atlas` 或与星图 Tab 切换（待定） |
| 册维度（MVP） | 按**类型**（信 / 日记 / 留言 / 时间线 / 照片）、按**年份** |
| 册维度（二期） | 主题标签、共同爱好、恋爱地图地点 |
| 卡片 | 封面图 + 标题 + 日期 + 类型角标；点开进详情 |
| 里程碑册 | 单独一栏，大卡 + 可爱文案 + 跳转关联内容 |
| 空状态 | 鼓励第一篇记录，**不做未解锁空槽** |

### 好玩点

- 册封面随数量变化（薄册 → 厚册）
- 集满某册轻庆祝（一次性的可爱 toast / 插画）
- 卡片背面可选一句摘要（二期 AI 或规则截取首段）

## 首页摘要

在 [home.md](./home.md) 占一小块，不抢主内容流：

- 一行：「N 个瞬间 · 最近点亮了 xxx」
- 可选：迷你星图预览或最近 3 张图鉴卡
- 点击进入星图

## 数据与 API（草稿）

### 策略

- **优先派生**：列表 / 统计从 `entry` + `asset` 查询，减少双写
- **可选物化**：`milestone_unlock` 表记录已触发的里程碑（防重复庆祝、查册快）
- **不建** `points` / `ledger` 表

### 端点（拟定）

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/memories/summary` | 节点总数、最近节点、里程碑数 |
| GET | `/api/memories/nodes` | 分页节点（星图 / 图鉴共用，query: `from`, `to`, `type`） |
| GET | `/api/memories/milestones` | 已解锁里程碑列表 |
| GET | `/api/memories/constellation` | 星图布局用坐标（MVP 可前端按时间排布） |

权限：空间成员只读；与现有 entry 可见性一致。
