# 动态与信箱首位新建入口施工计划

> 创建：2026-09-06 · 
> 状态：已完成

## 目标

在动态流与信箱列表第一项分别引入轻量速记卡与空白信笺卡，双端一视同仁无平台特化，彻底拒绝胶水代码与补丁。

## 步骤

1. 编写 `MomentComposeCard.tsx` 原子组件（刊物式排版，无假输入框与死图标，支持网格 feed 与列表 list 两种形态）；
2. 重构 `LetterComposeCard.tsx` 原子组件（融入 `orbit-env` 纸质信封、邮戳、封口折角、思源宋体排版，去除虚线与大加号）；
3. 在 `web/src/pages/Home.tsx` 内容首项挂载 `MomentComposeCard`，移除工具栏重复按钮与跨栏组件；
4. 在 `web/src/pages/ArticleList.tsx` 桌面首项挂载 `LetterComposeCard`，信箱工具栏保持纯净无重复按钮；
5. 验证自动化构建、单元测试与双端（Web 桌面与移动端）交互闭环。
