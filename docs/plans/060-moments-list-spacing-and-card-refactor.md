# 动态列表间距与独立卡片流重构

> 创建：2026-09-13 · 状态：已完成

## 目标

消除移动端动态流中多层边距叠加导致的横向拥挤，重构单列动态列表为独立呼吸卡片流，并确保不产生全局样式副作用，维护阅读界面的刊物版心契约。

## 步骤

1. 撤销全局污染：移除 `index.css` 中对全局 `.orbit-ui-container` 的粗暴覆盖，彻底恢复 `ArticleView`（阅读界面）等页面的安全边距与版心契约。
2. 职责精准归位：仅对动态列表流（`.orbit-home.orbit-ui-container`）在移动端进行横向 padding 清理，由外壳 `MobileShell` 的 `px-4` 统一管理 16px 视口边距。
3. 重构单列动态容器（`Home.tsx`）：移除 `divide-y` 单一大盒子包裹，采用 `flex flex-col gap-3 sm:gap-3.5` 的独立卡片流布局。
4. 重构单列动态卡片（`MomentCard.tsx`）：为 `layout="list"` 注入独立 `--surface` 卡片容器质感与边框阴影，作者信息降噪。
5. 重构速记卡（`MomentComposeCard.tsx`）：使其在 `layout="list"` 下作为流的首张独立微卡片，精简文案保持零度说明。
6. 类型检查与构建验证：运行 `npm run web:build` 确保零错误。

## 完成标准（可验证）

- [x] `npm run web:build` 打包通过，零类型与构建错误
- [x] 阅读界面（`ArticleView`）顶部返回条、正文与评论区恢复优雅的刊物版心留白，不再贴边
- [x] 动态首页单列条目拥有独立卡片与 12~14px 呼吸间距，不再粘连，两边边距适度舒展
- [x] 速记卡作为独立卡片优雅融入，无多余自指文案
