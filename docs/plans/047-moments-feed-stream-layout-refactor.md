# 动态流信息流排版重构与容器对齐施工计划

> 创建：2026-09-09 · 
> 状态：已完成

## 目标

彻底解决动态页单列列表模式下的“大头小身视觉割裂”与“形式倒挂臃肿方盒”问题：
1. **容器收敛与垂直对齐**：统一采用系统 `narrow`（672px）容器，工具栏与内容区严丝合缝等宽对齐；
2. **重构一体化单列流**：去卡片化，采用一体化纸面流（`divide-y` 极轻分割线），短文本不再有 80% 死白空间；
3. **元数据亲密性归位**：头像、作者、时间、标签紧凑归拢，无需横跨屏幕查阅；
4. **杜绝胶水代码**：纯粹依靠 Flex/Flow 自然对齐，无任何条件修补样式。

## 步骤

1. 改造 `web/src/pages/Home.tsx`：
   - 将主容器变更为 `<Container size="narrow" className="orbit-home" data-page="home">`；
   - 列表模式下改用一体化流容器承载条目与首位速记入口。
2. 改造 `web/src/components/MomentCard.tsx`：
   - 重构 `layout="list"`，去除独立边框与圆角，合并作者/时间/标签为同组元数据，支持长短文本舒适排版。
3. 改造 `web/src/components/moment/MomentComposeCard.tsx`：
   - 列表模式下适配一体化流首行形态。
4. 验证自动化测试与构建，确保 0 报错。
