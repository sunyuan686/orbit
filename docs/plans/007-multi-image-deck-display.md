# 内容多图合并展示（>=3张折叠堆叠 + 滑动切换 + 点击放大）施工计划

> 创建：2026-08-25  
> 状态：已完成  

## 目标

从第一性原理与杂志刊物阅读体验出发，优化正文中多图展示。当出现 3 张及以上连续相邻图片时，自动聚合折叠为拟物相纸堆叠卡片（4:3 画幅比），支持滑动手势洗牌切换、页码指示，并与全屏画廊 Lightbox 无缝联动。

## 步骤

1. 在 `web/src/lib/lightbox.ts` 中封装全屏画廊查看器 `openMultiImageLightbox`（支持多图翻页、键盘控制、触摸滑动手势、下拉退出与预加载）。
2. 在 `web/src/components/MultiImageDeck.tsx` 中实现堆叠相纸卡片组件，支持 4:3 拟物层叠、手势滑动切换、指示点与全屏联动。
3. 在 `web/src/extensions/OrbitImage.ts` 中升级 `ImageNodeView`：只读模式下智能检测连续 >=3 张图片组并挂载 `MultiImageDeck`，编辑模式保持独立控制。
4. 在 `web/src/index.css` 中补全多图堆叠卡片与全屏查看器的设计 Token 样式。
5. 运行 `npm run typecheck` 与 `npm run web:build` 验证构建与兼容性。

## 完成标准（可验证）

- [x] 类型检查与构建通过：`npm run typecheck`、`npm run web:build` 无报错。
- [x] 只读展示：连续 >=3 张图片自动聚合为单张 4:3 堆叠相纸卡片，1~2 张维持单图显示。
- [x] 交互体验：移动端横滑平滑切图，桌面端左右箭头与圆点点击直达，页码角标精准同步。
- [x] 全屏查看：点击图片打开全屏画廊并定位到当前图，支持滑屏翻页与下拉/Esc退出。
- [x] 编辑态完好：文章编辑模式下所有图片保持独立可编辑控制。
