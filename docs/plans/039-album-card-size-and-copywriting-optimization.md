# 相册卡片尺寸优化与文案降噪施工计划

> 创建：2026-09-07 · 
> 状态：已完成

## 目标

解决相册页面卡片尺寸过大（移动端单屏仅能容纳 1 张卡片）与文案信息冗余（作者、日期、系统标签、画蛇添足说明）的问题，重构为双列经典画册网格，遵循留白克制美学。

## 步骤

1. **相册列表页面改造（`web/src/pages/Albums.tsx`）**：
   - 网格重构：移动端采用双列 `grid-cols-2`，平板/桌面适配 `sm:grid-cols-3 lg:grid-cols-4`，收敛间距为 `gap-3 sm:gap-4`；
   - 封面画幅：改为 1:1 正方形相册比例（`aspect-square`），移除遮挡图片的浮层标签；
   - 信息降噪：卡片内彻底移除长文本描述、分割线、作者（「空间记忆」）与更新日期，仅保留相册标题与紧凑照片张数；
   - 统一词汇：消除「画册」异名，统一为「相册」，精简弹窗与空状态文案。
2. **相册详情页面微调（`web/src/pages/AlbumDetail.tsx`）**：
   - 移除「系统全量」冗余工程标签；
   - 修正返回文案为「返回相册」。
3. **自动化与构建验证**：
   - 运行类型检查 `npm run typecheck`；
   - 运行前端构建 `npm run web:build`。

## 完成标准（可验证）

- [x] 移动端相册列表呈规整双列网格，高度紧凑，单屏可完整浏览 4~6 本相册
- [x] 卡片彻底移除「系统」「全量」「空间记忆」作者名、日期、长文本描述与横向分割线
- [x] 卡片仅保留纯净相册名与轻量照片张数
- [x] 词汇统一为「相册」，新建弹窗与空状态文案自然真诚
- [x] `npm run typecheck` 与 `npm run web:build` 零错误通过
