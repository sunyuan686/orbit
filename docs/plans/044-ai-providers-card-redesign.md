# AI 供应商卡片规范化重构

> 创建：2026-09-09 · 
> 状态：已完成

## 目标

重构设置页「Orbit AI」中「供应商」模块的卡片结构与样式，彻底拆解连体多层横线大盒、替换粗糙的下划线文字链接、去除重复的 Field 标签、规范技术标题字体与状态 Badge，不写任何补丁与胶水代码。

## 步骤

1. **结构精简**：移除 `Section title="供应商"` 内部重复的 `<Field label="API 来源">`。
2. **独立卡片化**：将内置供应商（Cloudflare Workers AI、DeepSeek、阿里百炼）重构为独立独立的卡片容器（`orbit-ai-provider-card`），间距使用标准 `gap: 0.75rem`。
3. **状态与操作按钮规范**：
   - 统一使用 `font-sans`（无衬线黑体）渲染供应商名称；
   - 状态使用 Orbit 标准 `Badge`（`已就绪` / `未配置` / `开箱即用`）；
   - 操作入口统一采用 Orbit `Button` 体系（`size="sm"`、`variant="secondary" / "ghost"`），彻底移除下划线文本链接；
   - 官方域名作为微型副标展示，不再作为打断句意的裸露括号链接。
4. **编辑态内嵌收敛**：仅在编辑/配置时平滑展开密码框与操作区，常态下保持卡片纯净紧凑。
5. **CSS 规范治理**：在 `index.css` 中用标准 CSS Token 实现整洁的卡片样式，清理无用的历史层叠类。
