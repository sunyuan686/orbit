> 创建：2026-10-08 ·

## 目标

从第一性原理彻底消除“自建相册添加的照片出现在生活留影”的心智认知困惑：将全量投影的系统保留相册正名为直白纯净的《全部照片》（All Photos），让空间总图库与主题相册的逻辑关系自然透明，不打胶水补丁。

## 步骤

1. 在 `src/services/content/albums.ts` 中，将系统相册（`SYSTEM_ALL_ALBUM_ID = "all"`）标题正名为《全部照片》。
2. 在 `tests/albums-api.test.ts` 中同步更新相关用例断言为《全部照片》。
3. 在 `ROADMAP.md` 中同步更新对应描述。
4. 运行 `npm test` 与 `npm run web:build` 验证全链路零错误通过。
