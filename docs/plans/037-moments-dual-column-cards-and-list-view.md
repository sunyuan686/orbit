# 动态流双列卡片与单列列表重构施工计划

> 创建：2026-09-06 · 
> 状态：已完成

## 目标

彻底解决动态流视图切换“形同摆设”的问题，明确区分卡片与列表的职责边界：
1. **卡片模式为两列**：在双端（移动与桌面）统一提供小红书风格的双列卡片瀑布流，图片置顶、紧凑标题摘要、底部轻量作者栏；
2. **列表模式为列表**：提供舒适沉浸的单列图文流，支持完整文字阅读、多媒体自然缩放与作者信息置顶；
3. **切换按钮认知纠偏**：统一工具栏按钮图标与状态语义，杜绝反向图标带来的误导。

## 步骤

1. 改造 `MomentCard.tsx`：
   - 双列小红书卡片（图片置顶，占满卡片上部边缘；文字紧凑摘要；底部作者与日期）；
   - 单列信息流列表（作者栏置顶，正文完整长文本展开，底部大图与媒体）。
2. 改造 `MomentComposeCard.tsx`：
   - 适配双列网格与单列通栏两种形态。
3. 改造 `Home.tsx`：
   - 卡片模式采用左右双列独立 Flex 瀑布流（`flex gap-2.5 sm:gap-3.5` + 两列 `flex-1 flex flex-col gap-2.5 sm:gap-3.5`），每张卡片严格向上紧贴对齐，杜绝传统网格行高差异造成的留白空隙；
   - 列表模式采用 `flex flex-col gap-3.5 sm:gap-4 max-w-xl mx-auto w-full`；
   - 纠正工具栏图标及交互提示语义。
4. 验证自动化测试构建与 DevTools 双端视觉渲染。
