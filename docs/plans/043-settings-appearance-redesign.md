# 设置-主题与外观卡片规范化重构

> 创建：2026-09-08 · 
> 状态：已完成

## 目标

重构「主题与外观」设置模块，彻底解决外观模式卡片臃肿膨胀、各设置项栅格与对齐混乱、修辞文案画蛇添足的问题，建立符合 60-30-10 与克制美学的设计规范。

## 步骤

1. **外观模式**：由膨胀卡片重构为单行紧凑分段控制器（Segmented Control，带图标，高度 36px，限制最大宽度）。
2. **主题色**：重构为纯色色盘点阵（Color Swatches，圆形色圈 + 选中环/CheckIcon + 极简色名，去除外层矩形大方框和多余修辞词）。
3. **纸张底色**：统一为 4 等分紧凑微卡片，精简副标题文案。
4. **排版风格**：统一为 3 等分紧凑卡片，移除无意义 Badge 标签（“清爽/书信”），标题直接体现字体特色。
5. **阅读字号**：保持紧凑 3 等分比例，统一尺寸与视觉对齐。
6. **CSS 规范治理**：清理 `index.css` 中杂乱的冲突类，全部使用 CSS Token（`var(--color-...)`、`var(--type-...)`），严禁硬编码和胶水代码。

## 完成标准（可验证）

- [x] `npm run web:build` 编译检查通过
- [x] 浏览器验证：外观模式切换、主题色切换、底色切换、排版风格切换、字号切换功能完好
- [x] 视觉与排版：外观模式不再臃肿大卡片，栅格整齐，信息层级清晰
