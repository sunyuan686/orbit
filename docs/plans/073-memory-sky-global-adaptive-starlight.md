# 全局单屏记忆星空：璀璨主星、银河留白与静默偶遇回忆

> 创建：2026-10-10 · 状态：已完成

## 目标

解决记忆星空在移动端因星星过多（如 200+ 天）造成密集恐惧症与视觉拥挤的问题，同时彻底摒弃卡手的局部横向滚动、刻板图表年份轴与多余的功能按钮，实现优雅、留白且充满回忆温度的「单屏全局记忆星空」：
1. **全局整体性与浪漫留白**：天幕始终呈现全局时间轴（左旧右新），单屏仅点亮约 28～32 颗最有重量的璀璨高光星辰，每颗星平均间距保持在 45～60px 以上，留足呼吸空间；彻底移除天幕底部的年份刻度轴，消除刻板图表痕迹；
2. **重点高光稳固 + 静默偶遇回忆（方案 B）**：优先必选多瞬间/里程碑重点日（weight ≥ 2 或 count ≥ 3），将其作为星空基石稳固呈现；普通日常回忆星则在全时间段均匀分桶抽样，每次重新进入页面自动自然生成新种子更替，界面保持 0 多余操作按钮（Zero-Manual UI）；
3. **四角星芒视觉分级与 2D 碰撞避让**：全员采用四角闪光星芒（8px / 12px / 16px），经 2D 力导向间距松弛算法（最小硬性间距 ≥ 22px），彻底杜绝密集重叠；
4. **流光指星动态吸附交互**：单屏零横向滚动，手指滑过或点触时毫秒级动态吸附最近星辰并呼出对应日期的瞬间卡片，`touch-action: pan-y` 确保垂直滚动零阻碍。

## 核心实现

1. **抽样与排布算法（`web/src/pages/Memories.tsx`）**：
   - `sampleConstellation(days, target = 30, seed)`：重点日必选 + 分桶哈希随机抽样，保证代表性与偶遇感；
   - `buildSky(rawDays, seed)`：时间线性与分位数 50:50 融合，保证严格单调保序（从左至右）；移除图表年份坐标轴计算；
   - `relaxOverlaps`：多轮 2D 斥力松弛，强制保持星与星之间最小 22px 安全距离，避让右上角圆月区域。
2. **交互与组件**：
   - 挂载时 `useState(() => Math.floor(Math.random() * 10000))` 初始化会话种子，会话内稳定，每次重访自然焕新；彻底移除「漫步星河」按钮；
   - `DayStarButton`：28px 移动端舒适触摸热区，四角星芒 SVG 图标，选中金色光环扩散；
   - 指针滑动吸附（`handlePointerDown`, `handlePointerMove`, `selectNearest`）。
3. **样式（`web/src/index.css`）**：
   - 移除旧版密集圆点样式、年份刻度轴样式与漫步按钮样式，精简为四角星芒分级（`.orbit-memory-day-star--sm`、`--md`、`--lg`、`--featured`）；
   - 适配深色模式、轻量旋转相位与无障碍减弱动效（`prefers-reduced-motion`）。
