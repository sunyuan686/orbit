# 004 移动端与 PWA 搜索入口规范化计划

## 背景与目标
解决移动端及 PWA 竖屏模式下缺少全局搜索入口的问题，按照设计规范（`DESIGN.md`）补齐多端一致的搜索体验，包括顶栏图标直达、侧边栏导航收录及桌面端 `Cmd+K` 快捷键。

## 修改范围
- `web/src/components/Layout.tsx`：
  - 侧边栏导航列表中收录 `/search` 菜单项（跟随在「首页」之后）
  - 移动端顶栏右侧补充 🔍 按钮（`sm:hidden`，位于通知铃铛前）
  - 桌面端顶栏搜索输入框绑定 `ref`
  - 全局键盘监听统一支持 `Cmd+K` / `Ctrl+K` 搜索聚焦与导航

## 完成标准与验证
1. `npm run typecheck` 通过，无类型报错。
2. `npm run web:build` 成功打包。
3. 移动端/PWA 视图下，顶栏右上角与抽屉侧边栏均能清晰看到并操作搜索。
4. 桌面端下，`Cmd+K` 可快速聚焦搜索框。
