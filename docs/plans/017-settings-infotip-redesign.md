# 设置二级说明文字移除与 InfoTip 气泡化

> 创建：2026-08-30 · 
> 状态：已完成

## 目标

移除设置页面及各子面板中常驻的冗余二级说明文字，通过轻量 `InfoTip`（说明图标 + 交互气泡）按需查看，提升界面的整洁度与阅读舒适度。

## 步骤

1. 创建 `InfoTip` 基础组件（支持点击/触摸切换、桌面悬停、外部点击自动关闭、无障碍语义）；
2. 扩展 `Section` 与 `Field` 组件，原生支持 `info` 属性并内联渲染 `InfoTip`；
3. 更新 `index.css`，配置符合 Orbit 规范的图标与气泡样式（60-30-10 配色、阴影与字阶）；
4. 改造 `Settings.tsx`（主题与外观、个人资料等）及各设置子面板（空间档案、主动触达、AI 设置、飞书连接、通知、API Token 等）；
5. 运行类型检查并验证交互效果。

## 完成标准（可验证）

- [x] `npm run typecheck` 通过
- [x] `npm run web:build` 通过
- [x] 浏览器验证：设置各页面的二级标题与配置项不再常驻大段冗余灰字
- [x] 浏览器验证：点击说明图标正常弹出说明气泡，再次点击或点击空白处关闭
