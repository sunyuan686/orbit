# 相册详情全屏大图丢失左右切换与手势导航

> 创建：2026-09-07 · 
> 状态：已修复

## 现象

重构相册并使用 `AlbumDetail.tsx` 承接画册与全量生活流后，在 Web 桌面端和 PWA 移动端点击照片打开全屏大图预览时，无法通过左右按键、切换箭头或滑动触摸手势切换上一张/下一张照片，且缺少下拉阻尼退出（Pull-to-dismiss）手势与照片张数指示器。

## 期望行为

1. **Web 端**：点击全屏大图后，左右两侧显示半透明切换箭头；支持键盘 `ArrowLeft`（上一张）、`ArrowRight`（下一张）、`Escape`（退出）。
2. **PWA 移动端**：支持横向跟手滑动手势切换下一张/上一张照片，支持下拉阻尼拖拽缩放退出手势。
3. **细节体验**：左上角显示当前照片序号（如 `3 / 311`），自动对相邻前后照片进行静默预加载，控制栏闲置自动淡出。

## 根因与修复

### 根因
在内容类型收敛与相册重构中，`/gallery` 路由重定向到了 `/albums/:id`（`AlbumDetail.tsx`）。在编写 `AlbumDetail.tsx` 时，大图预览仅实现了一个单张静态图片的普通弹窗，未迁移原 `Gallery.tsx` 中成熟的手势、快捷键及切图上下文。

### 修复
遵循第一性原理与高内聚组件化原则，拒绝在页面内粘贴零散补丁：
1. 封装通用高内聚原子组件 `web/src/components/PhotoLightbox.tsx`，集中管理照片索引切换、相邻图片预加载、键盘监听（`ArrowLeft` / `ArrowRight` / `Escape`）、触摸滑动手势与下拉退出手势；
2. 100% 复用既有 `.orbit-gallery-lightbox-*` 样式体系与 `GalleryImage` 的 `lightbox` 骨架变体；
3. 在 `AlbumDetail.tsx` 中接入 `<PhotoLightbox />`，通过当前索引受控驱动大图浏览，实现跨端体验一致闭环。
