# 相册打开大图出现白底闪烁与延迟加载

> 创建：2026-10-07 · 状态：进行中

## 现象

在相册列表（`AlbumDetailPage`）中点击任意照片进入大图预览（`PhotoLightbox`）时，屏幕先闪烁出现一块空白的纯白色矩形卡片，等待数百毫秒至一秒网络下载原图后，照片才突然显现。

## 期望行为

1. **点击即显（0ms 零白屏）**：点击相册中已浏览的照片时，大图应瞬间无缝呈现画面，绝无任何刺眼白底色块闪烁；
2. **渐进式平滑过渡**：优先复用相册列表中已加载至内存的缩略图（`thumbUrl`）作为即时预览底图，高清原图（`url`）在后台加载完成后无缝叠印淡入；
3. **尺寸与比例稳定**：大图卡片在加载前后保持画面比例稳定，避免尺寸抖动。

## 根因与修复（第一性原理）

1. **原图加载期间图片完全隐形（`opacity: 0`）与纯白面板裸露**：
   - `GalleryImage` 组件默认设置 `opacity: 0` 直至原图触发 `onLoad`；而 `.orbit-gallery-lightbox-panel` 设置了 `background: var(--color-surface)`（纯白色），原图下载期间图片透明，裸露出的就是底层的纯白面板。
2. **存量照片 BlurHash 缺失（数据断层）**：
   - 数据库中 300+ 张存量照片的 `blurhash` 字段为 NULL，导致模糊占位层完全无法生成。
3. **列表已缓存缩略图未复用（架构最佳实践缺失）**：
   - 列表网格中的缩略图（`thumbUrl`）已驻留在浏览器缓存中，但 `PhotoLightbox` 仅向 `GalleryImage` 传递了 `currentPhoto.url`，未传递 `thumbUrl`，导致大图组件强行从零发起大图网络请求。
4. **修复方案**：
   - `GalleryImage` 支持双层渐进加载（`src` + `thumbUrl`）：当高清大图处于加载中时，立即展示已缓存的 `thumbUrl` 占位层；
   - CSS 声明高低清分层与淡入叠印：高清图在顶层加载完成时淡入，底层占位图平滑覆盖，消灭任何渲染空窗期；
   - 同步自动推断比例（Aspect Ratio）：缩略图一旦就绪即可自动计算比例，消除高低清切换过程中的尺寸跳动。
