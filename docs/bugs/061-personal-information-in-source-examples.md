# 示例页面与开发文档包含个人信息

> 创建：2026-10-11 · 状态：已修复

## 现象

原型页面包含个人生活记录，测试和开发文档包含个人称呼、本机绝对路径，部署配置也直接关联具体实例。

## 根因与修复

- 删除 `prototype-scratch-card.html` 和 `web/public/palette-and-typography.html`。
- 示例改用通用称呼，文档文件链接改为仓库相对路径。
- API 测试使用内存数据库和虚构账号，移除硬编码用户 ID 及对本地业务数据库的依赖。
- AI 助手默认名称改为通用的 `Orbit`，已保存的自定义名称不变。
- CORS 使用已有的 `BETTER_AUTH_URL` 配置；公开快照使用占位部署配置。
- 公开同步使用独立提交，避免引入尚未公开的私人提交历史；既有 Git 历史不改写。

## 回归验证

- 当前公开快照隐私扫描通过；两个页面均不再出现在源码和新构建产物中。
- 62 项测试（含配置域名的 CORS 回归检查）、类型检查、前端构建、PWA 检查与公开版本 Worker 打包预检均通过。
