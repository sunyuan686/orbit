# Orbit 配色与字体排版全景设计指南 (Palette & Typography Guide)

本文档定义了 Orbit 平台的核心视觉系统规范，包含 **60-30-10 黄金色彩法则**、**4 组主题色全色阶体系**、**4 种画布底色与纸质微颗粒机制**、以及 **经典三元字体架构与间距韵律**。

---

## 1. 60-30-10 黄金色彩法则

```
┌─────────────────────────────────────────────────────────────┐
│ 60% 画布底色 ── 月石清白 + 5% 纸质微颗粒                      │
│   ↓                                                         │
│ 30% 墨水排版 ── 24px/18px 宋体标题 + 15px/1.72 呼吸正文      │
│                 + 12px JetBrains Mono 等宽时间戳             │
│   ↓                                                         │
│ 10% 主题高光 ── 唯一 CTA 纯色按钮 + 2px 垂直金句引线          │
└─────────────────────────────────────────────────────────────┘
```

### 比例分解与组件映射
- **60% 基础画布 (Canvas & Space)**：
  - 全屏背景底色 (`var(--bg)`)：月石清白 `#f8f8fa` / `oklch(0.985 0.002 250)`；
  - 容器表面 (`var(--surface)`)：纯白 `#ffffff`（深色模式下为 `#1a1a1d`）；
  - 负空间留白：卡片间距、段落边距。
- **30% 结构墨水 (Ink & Typography)**：
  - 核心标题与主文字 (`var(--text-primary)`)：深炭墨黑；
  - 正文与描述 (`var(--text-secondary)`)：中度墨灰；
  - 时间与刻度 (`var(--text-muted)`)：浅铅笔灰；
  - 容器骨架 (`var(--border)`, `var(--border-light)`)：1px 中性微灰线；
  - 探索入口：单色线性几何图标（中性灰轮廓，告别彩色糖果盒）。
- **10% 焦点高光 (Accent & Spark)**：
  - 全站唯一实心主操作按钮 (CTA，如「+ 写第一篇日记」)；
  - 阅读流中金句段落左侧 2px 垂直引线；
  - 状态呼吸圆点（如顶部相伴天数左侧的微点）；
  - 输入框聚焦态外轮廓发光 (`box-shadow: 0 0 0 3px var(--accent-soft)`)。

## 3. 画布底色与纸质微颗粒机制

### 4 种画布底色
1. **月石清白 (`moonstone`)**（默认）：`oklch(0.985 0.002 250)`，纯净无黄色衰老感；
2. **画廊冷灰 (`studio`)**：`#f4f4f6`，现代画廊白墙；
3. **冷杉薄雾 (`mist`)**：`oklch(0.985 0.004 165)`，微冷杉青白；
4. **暖石燕麦 (`warm-linen`)**：`oklch(0.982 0.008 75)`，羊绒纸质感。

### 物理微颗粒感 (Physical Grain Texture)
- 通过轻量级 SVG `feTurbulence` 噪点渲染在 `body::before` 上，`pointer-events: none`；
- 默认强度为 **5.0%（艺术棉纸·推荐）**，支持在系统设置中 0% ~ 15% 自由调节。

## 4. 经典三元字体架构 (The Classic Trio Stack)

```css
:root {
  /* 1. 标题 (Serif) —— 出版物文学温度 */
  --font-serif: "Source Serif 4", "Songti SC", "Noto Serif SC", STSong, Georgia, serif;
  
  /* 2. 正文 (Sans) —— 现代温润黑体，长篇夜读清晰不晕眼 */
  --font-sans: "Inter", -apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
  
  /* 3. 时间与英文 (Mono) —— 物理等宽对齐，老钟表与铅印日历秩序感 */
  --font-mono: "JetBrains Mono", ui-monospace, "SF Mono", Menlo, Monaco, Consolas, monospace;
}
```

### 黄金字阶与间距规范 (1.200 Minor Third)

| 层级 | 字号 (rem / px) | 行高 (Line Height) | 字间距 (Tracking) | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Display** | `1.5rem` (24px) | `1.32` | `+0.015em` | 页面大标题、主空间扉页 |
| **Heading** | `1.125rem` (18px) | `1.45` | `+0.01em` | 模块大标题（如“最近动态”） |
| **Body** ★ | `0.9375rem` (15px) | `1.72` | `+0.01em` | 核心长篇正文、日记、信件 |
| **Secondary** | `0.8125rem` (13px) | `1.55` | `+0.01em` | 卡片副标题、按钮文案、输入框文字 |
| **Mono** | `0.75rem` (12px) | `1.35` | `+0.04em` | 时间戳 `2026 · 08 / 15`、相伴天数 |
| **Micro** | `0.6875rem` (11px) | `1.30` | `+0.02em` | 极小徽章、辅助提示 |

## 5. 组件开发铁律：杜绝硬编码

1. **颜色**：一律使用 CSS 变量（`var(--bg)`, `var(--surface)`, `var(--text-primary)`, `var(--accent)` 等），**严禁直接写死 `#2563eb`、`#10b981` 等颜色**；
2. **字体**：一律使用 `var(--font-serif)`、`var(--font-sans)`、`var(--font-mono)`；
3. **字阶与间距**：字号使用 `rem`，行高与正文字距继承自全局规范，不写随意值；
4. **图标**：单色线性几何图标，颜色继承父级 `currentColor` 或 `var(--text-secondary)`，仅在 hover 时升温为 `var(--accent)`。
