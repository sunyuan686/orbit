# PWA 主动更新与缓存控制

> 创建：2026-09-03 · 
> 状态：已完成

## 背景与目标

解决 PWA 独立应用模式（iOS / 桌面）无浏览器刷新按钮、仅能依赖后台 15 分钟节流被动检测更新，以及缓存异常时用户无法主动拉取最新代码的问题。提供主动「检查更新」、「立即更新」与「清除缓存并刷新」的完整能力。

## 交互与界面

1. **设置 -> 关于 (`AboutSettingsPanel`)**：
   - **版本信息行**：
     - 版本号展示（如 `Orbit v0.2.0`）；
     - 状态徽章：`检查中…` / `发现新版本` (accent) / `已是最新`；
     - 操作按钮：发现新版本时展示高亮「立即更新」；平时展示「检查更新」按钮（支持 loading 态并触发 Toast 提示）。
   - **缓存与同步行**：
     - 说明：“若代码更新后界面未刷新，可清除本地缓存重新拉取”；
     - 操作按钮：「清除缓存并刷新」（清除 CacheStorage、注销 SW 并硬刷新页面）。
2. **全局悬浮横幅 (`SwUpdatePrompt`)**：
   - 消费全局统一更新状态，检测到新 SW 就绪且未手动关闭时在底部浮动展示「新版本可用」+「立即刷新」。
3. **入口红点联动 (`UserAccount` & `Settings`)**：
   - 当检测到新版本等待激活时，设置入口显示轻量高光圆点提示。
