# Feed 流下拉刷新 (Pull-to-Refresh)

> 创建：2026-10-09 · 状态：已完成

## 背景与目标

解决移动端/PWA 场景下 Feed 流无法通过触屏手势下拉刷新的问题。
基于第一性原理，不引入外部第三方重型手势库，不侵入修改全局滚动模型，遵循 Orbit 60-30-10 极简克制美学与 Zero-Manual UI 准则，提供平滑自然的触控下拉体验与确定性状态反馈。

## 交互与界面

1. **手势触发与阻尼动力学**：
   - 仅在触摸设备且当前滚动视口 `scrollTop <= 0` 时响应下拉手势。
   - 严格进行手势矢量夹角判定（纵向偏移必须显著大于横向），防止与系统边缘侧滑返回手势竞争。
   - 渐进阻尼（位移比例约为 42%），下拉临界阈值为 56px，最大物理位移约束在 80px。
   - 触达阈值触发微触觉反馈（`navigator.vibrate?.(10)`）。
2. **克制视觉呈现**：
   - 顶部居中浮现 32px 纯色圆角气泡（`--color-surface` 配合微边框 `--color-border` 与微投影），内嵌 14px 极简 Spinner（Token `--color-text-secondary`）。
   - 下拉过程中，Spinner 随位移角度比例旋转；达到阈值并释放时，保持 48px 悬停并自动匀速旋转，展示加载状态。
   - 严禁加入“下拉刷新”、“释放立即更新”等界面自指说明文字。
3. **数据同步与终态反馈闭环**：
   - 释放后调用页面的 `refetch` 刷新数据；
   - 保证至少 260ms 的加载过渡期，避免网络过快导致的瞬时闪烁；
   - **成功终态（Success）**：指示器平滑变换为 14px 微型对勾（`CheckIcon`，`--color-accent`），伴随 12ms 触觉脉冲（Haptic Tick），停留 350ms 后通过 CSS 弹性曲线收拢，告知用户已确认最新状态；
   - **失败终态（Error）**：指示器变为警告叹号（`AlertIcon`，`--color-danger`），伴随双重告警触觉并在界面显式弹出 `toast.error` 报错，绝不静默吞噬失败；
   - 视图内容回弹完成后，状态自动重置为 `idle`。
4. **辅助协同（底栏点击）**：
   - 当用户在首页顶部再次轻触底栏「动态」Tab 时，直接触发数据刷新，与手势形成互补。

## 回归验证

- 移动端触屏在 Feed 顶部向下拉动，顺畅呼出指示器并触发数据重新拉取。
- 向上滑动浏览历史时，100% 保持原生惯性滚动，无任何拦截或卡顿。
- 横向滑动（系统侧滑返回等）不误触下拉刷新。
- 刷新完成后平滑回弹收拢，视图内容无重排抖动。
