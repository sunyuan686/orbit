# 时光刮刮乐（每日限定 + 随心漫游）

> 创建：2026-08-25 · 
> 状态：已完成

## 背景与目标

解决首页刮刮彩每次打开均固定展示最新动态、缺乏神秘感与仪式感的问题。将刮刮乐升级为「每日专属同频卡 + 随心漫游探索」双模式，为情侣日常注入拆盲盒与偶遇旧时光的温度。

## 交互与界面

1. **每日限定卡（双人同频）**：
   - 每天 0 点刷新一张专属卡片，情侣双方看到的卡片完全一致；
   - 覆盖香槟银金属涂层，中央提示「✨ 今日限定回忆 · 划开揭晓 ✨」；
   - 划开面积 > 30% 自动渐隐揭晓底层内容，并记录当天已揭晓状态；
   - 当天再次进入首页时，卡片直接保持已揭晓状态，无需重复刮涂层。
2. **卡片抽取优先级（每日限定）**：
   - **优先级 1 · 那年今日**：命中历史年份中同月同日（MM-DD）的记录（日记/信件/相册/时光轴），徽标为 `✨ 那年今日 · N年前的今天`；
   - **优先级 2 · 相伴里程碑**：恰逢恋爱百天/整年纪念日等节点，徽标为 `💖 相伴里程碑`；
   - **优先级 3 · 历史旧回忆**：以当天日期为确定性种子从 > 7 天前的历史记录中打捞一段，徽标为 `✨ 今日回忆 · 类型`；
   - **优先级 4 · 心动默契拷问**：若暂无历史记录，按日轮换一道双人互动话题，徽标为 `🎲 今日默契拷问`。
3. **随心时光漫游（无限刮卡）**：
   - 刮开后右上角展示按钮「🎲 时光漫游 · 再刮一张」；
   - 点击后重新覆盖涂层（提示「🚀 时光漫游 · 划开偶遇旧时光 🚀」），并从全量历史中随机抽取另一段回忆，支持连续漫游。

## 回归验证

- [ ] 打开首页，正确加载今日专属限定卡片；
- [ ] 刮开涂层后，刷新页面保持揭晓状态；
- [ ] 点击「时光漫游 · 再刮一张」，涂层重新覆盖并成功切换为随机新卡片；
- [ ] 各类卡片点击跳转链接正常。
