# PWA 引导安装与全平台适配

> 创建：2026-08-26 · 
> 状态：已完成

## 背景与目标

解决移动端及桌面端访问 Orbit 时的 PWA 安装触达问题：
1. 提供 Chromium 平台一键触发原生安装；
2. 解决 iOS Safari 不支持 `beforeinstallprompt` 事件的问题，提供杂志排版风格的分步图文安装指南；
3. 为 iOS Web Push 推送开启打通先决条件；
4. 保证克制优雅的杂志体验，避免频繁弹窗打扰用户（具备 14 天免打扰与独立模式自动隐藏）。

## 交互与界面

1. **通知铃铛业务场景驱动 (`NotificationBell`)**：
   - 当用户在普通浏览器模式（`!isStandalone`）点击顶栏 🔔 铃铛查看通知列表时，在通知浮层底部温和显示一条场景提示条：“添加到主屏幕，不错过锁屏通知”；
   - 提供「去添加」操作按钮（直通三步引导弹窗）与「×」关闭按钮（14 天免打扰机制）；
   - 用户安装后（`isStandalone` 模式）自动永久隐藏，零侵入、零打扰。
2. **设置中心独立「关于」页面 (`AboutSettingsPanel`)**：
   - 位于「设置」→「系统」→「关于」，展示应用版本（`v0.2.0`）、运行模式（独立应用 / 浏览器网页）；
   - 水平键值卡片排版，克制利落，提供常驻的「查看安装指引」入口。
3. **三步图文指引弹窗 (`PwaInstallGuideModal`)**：
   - 针对 iOS Safari 或需要手动操作的环境，提供清晰的三步指引卡片（分享图标、添加到主屏幕、添加完成）。
4. **日常浏览与设置中心零打扰**：
   - 「主题与外观」设置保持纯粹的视觉调节，不强塞无关的客户端安装卡片；
   - 用户头像菜单保持纯粹的身份与会话层定位；
   - 桌面端完全依托浏览器原生地址栏（Omnibox）安装图标，不弹出任何打扰条。

## 回归验证

- `npm run typecheck`
- `npm run web:build`
- `node web/scripts/verify-pwa.mjs`
- 浏览器多端模拟验证（Chromium 事件捕获、iOS 图文引导、14天免打扰存取、独立模式识别）
