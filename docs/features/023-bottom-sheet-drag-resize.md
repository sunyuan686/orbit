# 底部抽屉拖拽调节大小与手势交互 (BottomSheet Drag Resize)

## 背景

在移动端与桌面端体验中，底部抽屉顶部的横条胶囊为 Drag Handle（拉手指示器）。此前该拉手仅有静态视觉效果，未绑定手势交互，导致用户尝试拖拽无响应。

## 交互设计规范

1. **手势驱动**：采用 HTML5 Pointer Events，通过 `setPointerCapture` 锁定光标，移动端触摸与桌面端鼠标拖拽行为统一，1:1 跟手零延迟。
2. **档位与吸附 (Snap Points)**：
   - **默认/便携档 (Compact)**：自然内容高度（约 440px），轻快便携；
   - **沉浸大屏档 (Expanded)**：88vh 高度，向上拖拽或轻点拉手展开，适合长文与多媒体编辑；
   - **下拉关闭 (Dismiss)**：便携状态下向下拖拽超阈值，抽屉顺滑向下划出屏幕并关闭。
3. **内容响应**：
   - 内部主体采用弹性盒布局，大屏状态下文本输入区自动弹性伸展 (`flex-1`)，提供开阔编辑空间。
4. **无障碍**：
   - 拉手添加 `role="slider"`，支持 `ArrowUp` 展开与 `ArrowDown` 收起，支持 Escape 键退出。
