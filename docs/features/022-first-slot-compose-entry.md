# 动态与信箱首位新建入口

> 创建：2026-09-06 · 
> 状态：已完成

## 背景与目标

解决 Web 桌面端与 PWA 移动端在动态流与信箱列表顶部缺少直观新建入口的问题。通过在首条数据位置放置轻量速记卡与空白信笺卡，实现双端 100% 同构（零 `isMobile` 设备嗅探、零媒体查询隐藏补丁），兼顾视觉留白美感与即时记录效率。

## 交互与界面

1. **统一的单一首位新建入口**：
   - 动态流与信箱列表均采用一致的单一入口哲学，不在工具栏重复放置新建按钮，将新建引导自然融入内容流首项。
2. **动态首位引导卡 (`MomentComposeCard`)**：
   - 位于动态流首个卡片槽位（网格与列表同构，默认降序最新优先且无筛选时展示）。
   - 纯白 `--color-surface` + 1px `--color-border-light`，圆角与阴影与普通动态卡完全统一。
   - **极简真诚文案，剔除煽情赘述**：仅保留“动态”微标 + 标题“记录动态…” + 动词行动“开始记录 →”，彻底去除文艺腔与画蛇添足的修饰。
   - 点击唤起即时创作抽屉（`QuickComposeSheet`），支持文字、传图、语音、标签与即时置顶发布。
3. **信箱首位雅致信笺卡 (`LetterComposeCard`)**：
   - 位于信箱桌面（`orbit-desk`）首个信件卡片位。
   - 采用温润信纸质感（`--letter-paper` + `1px` 实线边框），彻底抛弃虚线边框与大加号。
   - 继承信封折口（`orbit-env-flap`）、邮戳印章（`新信 · Orbit`）与火漆点缀（`orbit-env-seal`）。
   - **极简排版**：标题“写一封信…”，落款指引“开始写信 →”，剔除口号式长段落描述，回归纯粹信笺质感。
   - 点击跳转 `/letter/new` 沉浸式信纸写作。
4. **时空纯净性**：
   - 当用户激活历史筛选（年份、作者、标签）或切换升序排列时，首位新建卡自动隐藏，保证时间序列的绝对纯净。

## 回归验证

- 动态流首项卡片展示自然，位于网格第一位，无跨栏违和感，点击拉起抽屉完成发布闭环；
- 信箱首项信笺卡展示优雅，无虚线与生硬大加号，点击跳转 `/letter/new`；
- 动态与信箱工具栏均无冗余新建按钮，职责单一聚焦于检索与排序；
- 筛选或升序时新建卡自动隐去；
- 零 `isMobile` 设备嗅探、零媒体查询隐藏胶水代码。
