# 内容多图合并展示 (`MultiImageDeck`) 设计稿

> 架构归属：产品能力方案 · 归档于 `docs/features/015-multi-image-deck.md`  
> 创建：2026-08-25  

---

## 1. 背景与目标

在随想、日记、文章等内容中，用户经常一次性上传多张照片记录同一事件。当连续图片较多时，传统单图依次垂直平铺会导致页面极其冗长（“刷屏”），割裂正文和评论区，降低阅读体验。

**目标**：
1. **智能折叠**：当内容中出现 3 张及以上连续图片（`>= 3`）时，自动合并展示为紧凑的**拟物相纸堆叠卡片**。
2. **轻量交互**：支持移动端横滑洗牌切换、桌面端微翻页按钮与圆点直达，显示页码指示（如 `1/4`）。
3. **全屏画廊联动**：点击任意图片即进入全屏 Lightbox 画廊，支持平滑手势翻页与下拉退出。
4. **编辑态隔离**：只在只读态进行折叠渲染，编辑态保留单图独立参数调整与控制。

---

## 2. 核心交互与界面设计

### 2.1 堆叠相纸卡片 (`MultiImageDeck`)
- **画幅比例**：固定 `4:3` 比例，最大高度约 280px，自适应屏幕宽度。
- **视觉层级**：
  - 顶层主图：完整圆角（`rounded-xl`），支持居中自适应缩放（`object-fit: cover`）；
  - 底层纸质卡片：后方露出 1~2 层微旋转（-2°、1.5°）的纸质卡片边缘与柔和阴影，营造拍立得相纸堆叠感；
  - 角标指示器：右上方浮动半透明胶囊，显示当前张数 `当前/总数`（如 `2 / 5`）；
  - 底部指示点：悬浮微圆点，当前激活项高亮展开为胶囊状。

### 2.2 全屏画廊查看器 (`Lightbox`)
- 支持多图数组预览与初始定位。
- 键盘快捷键：`ArrowLeft` / `ArrowRight` 前后翻页，`Escape` 退出。
- 移动端手势：左右滑动切图，下拉 > 90px 顺畅退出。
- 智能预加载：自动预加载前后相邻图片，秒切无白屏。

---

## 3. 实现与架构

- `web/src/lib/lightbox.ts`：全局单例/函数式多图 Lightbox 查看器。
- `web/src/components/MultiImageDeck.tsx`：堆叠卡片组件与手势控制器。
- `web/src/extensions/OrbitImage.ts`：ProseMirror 节点智能相邻检测与 Deck 挂载。
