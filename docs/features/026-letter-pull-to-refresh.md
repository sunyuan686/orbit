# 信箱下拉刷新 (Letter Pull-to-Refresh)

> 创建：2026-10-09 · 状态：已完成

## 背景与目标

信箱（`/letter`）作为双人异步书信通信的核心载体与四大常驻保活 Tab 之一，在移动端需具备主动下拉同步新信件的能力。
复用已有的极简 `PullToRefresh` 统一容器，为信箱提供丝滑一致的触屏手势下拉刷新与底栏 Tab 联动刷新能力。

## 交互与界面

1. **手势与动力学**：
   - 保持与动态流完全一致的阻尼（42%）、阈值（56px）与微触觉反馈（10ms）。
   - 仅在顶部（`scrollTop <= 1`）向下拉动时生效，不拦截阅读翻信与横滑手势。
2. **视觉语言**：
   - 零文字提示（Zero-Manual UI），顶端弹性居中微型单色 Spinner（14px）。
3. **数据刷新联动**：
   - 释放手势后重新拉取信件列表与未读状态（`letterQuery.refetch()` 与 `statusQuery.refetch()`）。
   - 在底栏「信箱」Tab 顶部再次点击时，自动联动触发刷新。

## 回归验证

- 在移动端 `/letter` 顶部向下拉动，顺畅呼出指示器并刷新信件列表。
- 底栏「信箱」Tab 处于顶部时再次点击，触发同步刷新。
- 上滑浏览信件列表时 100% 保持原生顺畅滚动。
