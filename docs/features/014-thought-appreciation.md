# 短随想 (`note`) 与记录感谢 (`appreciation`) 设计稿

> 架构归属：产品能力方案 · 归档于 `docs/features/014-thought-appreciation.md`
> 创建：2026-08-02

---

## 1. 背景与目标

目前 Orbit 的富文本编辑器采用沉浸式文档大画布模式，适合撰写长日记与深度总结。但在恋爱日常场景中，存在两个高频轻量需求：
1. **短随想 (`Note`)**：随手记录一两句话与生活瞬间，零心理负担，不强制写标题与大文章。
2. **记录感谢 (`Appreciation`)**：及时记录与表达对对方付出的微小感恩（如照顾、买咖啡、听抱怨、精心准备的惊喜），通过暖心卡片与回忆池形成“情感存钱罐”。

**目标**：在不破坏 `entry` 统一表架构的前提下，扩充 `note` 与 `appreciation` 两种新 `type`，提供轻量创作弹窗与专属渲染样式。

---

## 2. 核心交互与界面设计

### 2.1 轻量创作弹窗 (`ComposeModal`)
- **分段控制器**：顶部提供 `[ 随想 | 感谢 | 链接 | 摘录 ]` 快捷切换。
- **随想模式 (`note`)**：
  - 取消强制标题栏，聚焦正文输入框（Placeholder: *"记录这一刻的随想…"*）。
  - 图片上传队列（媒体卡片 1~4 图响应式拼图）。
- **感谢模式 (`appreciation`)**：
  - 输入框 Placeholder: *"记录此刻想要感谢对方的小细节…"*
  - 情感微徽章选择（可选分类：`#暖心饮品` `#美味餐食` `#贴心照顾` `#陪伴倾听` `#默契配合` 等）。

### 2.2 发布态卡片渲染
- **`NoteCard`**：上文下图排版，使用 `MediaGallery` 九宫格显示缩略图。
- **`AppreciationCard`**：
  - 柔粉/暖金微渐变背景衬底。
  - 左上角显示微光爱心/感恩徽章，右下角带有签署信息（如：*“来自 XX 的心意”*）。

## 4. 外部集成与沉淀

1. **飞书通知**：发布“记录感谢”时自动向对方触达专属粉暖色调交互卡片。
2. **恋爱记忆 (`/memories`)**：在记忆池中汇总“感恩回响 (Gratitude Echoes)”数据统计与卡片回看。
