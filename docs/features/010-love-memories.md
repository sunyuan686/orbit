# 恋爱记忆（星图 + 图鉴）

> 把已有内容织成「我们的回忆」：点点滴滴都是成就，好玩可爱向。  
> 创建：2026-07-13
> 进度见 [ROADMAP.md](../../ROADMAP.md)（Phase E · 恋爱记忆）。  
> 数据来自 `entry`、相册关联图、空间档案纪念日；不新增写作类型。

---

## 目标

回答「我们在一起积累了什么」，而不是「谁得了多少分」。

- **星图**：按「有记录的日子」点亮，一点一天，点开看当天瞬间
- **图鉴**：按类型 / 年份翻卡片；里程碑与星座墙；规则主题分册
- **原则**：回忆即成就；不做积分商城、扣分、双人排行、每日任务

气质：**俏皮、可爱、有小庆祝**（里程碑弹层、星座文案）。

---

## 非目标

| 不做 | 理由 |
|------|------|
| 爱情小店 / 兑换券 | 与产品方向不符 |
| 可消耗积分、扣分 | 易变关系 KPI |
| 个人排行榜、段位 | 双人空间不宜竞争 |
| 每日签到、任务清单 | 与「无压力记录」冲突 |
| 用户单独维护「游戏条目」 | 成就来自真实内容 |

## 核心概念

### 记忆节点

只读聚合自 `entry`；图鉴卡 / 主题册 / 某日详情均基于节点。

| 来源 | 节点粒度 | 说明 |
|------|----------|------|
| `entry`（diary / timeline / message） | 一篇一节点 | — |
| `entry`（letter） | **每封信一节点（含回信）** | 不按线程合并 |
| `gallery` `asset` | **不单独成节点** | 有图 entry 用封面 / weight 提亮 |
| 空间档案纪念日 | 不单独成星 | 驱动「在一起第 N 天」类里程碑 |
| `memo` | 不计入 | 对齐 activity |

### 里程碑

规则硬编码于 `src/services/love-memories.ts`；命中后写入 `milestone_unlock`（`unlocked_at` / `celebrated_at`）；**不写 audit**。

| 类别 | 示例 |
|------|------|
| relationship | 在一起 7 / 30 / 100 / 365 / 1000 天 |
| creation | 首信、首回信、日记 10 / 50 / 100 篇 |
| streak | 连续记录 7 / 30 天（读 activity） |
| gallery | 相册 50 / 100 张 |
| constellation | 组合条件星座彩蛋（见下） |

一次扫描新解锁 **>3** 条视为历史回填：直接标已庆祝，避免飞书与弹层轰炸。  
新解锁 ≤3：站内庆祝弹层 +（可选）飞书 interactive card。

### 星座彩蛋

已落地。组合已达成里程碑解锁，独立展示于星图 / 图鉴「星座」区。例：鱼雁往来、日日相记、一周年轨、千日同辉、百帧映画、双人笔迹。

## 星图 `/memories`

| 项 | 说明 |
|----|------|
| 布局 | **按日聚合网格**（一点一天，按月分组换行）；不做密排横滑 SVG |
| 交互 | 点某日 → 下列出当天节点，可进原文 |
| 视觉 | 类型分色；同日多篇显示角标数量 |
| 文案 | 「N 个有记录的日子」；避免得分 / 排名 |

与 activity：热力图看「有多密」，星图看「哪几天有回忆」。

## 数据与 API

### 策略

- 节点 / 主题：**派生**自 `entry`（+ asset 封面）
- 里程碑状态：**物化** `milestone_unlock`
- 不建 `points` / `ledger` / 节点物化表

### 端点

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/memories/summary` | 总数、byType、里程碑数、最近节点、最近点亮 |
| GET | `/api/memories/nodes` | 分页节点（`type` / `year` / `hasCover` 等） |
| GET | `/api/memories/milestones` | 同步解锁并返回列表；新解锁可异步飞书推卡 |
| POST | `/api/memories/milestones/celebrate` | 标记 `celebrated_at` |
| GET | `/api/memories/themes` | 规则主题分册 |
| GET | `/api/memories/timeline` | 旧等距布局（保留；星图 UI 已改按日网格） |

权限：空间成员，需登录。

### 主要代码

| 区域 | 路径 |
|------|------|
| 服务 | `src/services/love-memories.ts` |
| API | `src/api/memories.ts` |
| 表 | `milestone_unlock`（migration `0013`） |
| 前端 | `web/src/pages/Memories.tsx`、`MilestoneCelebrate.tsx`、首页 `Home.tsx` |
| 客户端 | `web/src/lib/api.ts`（`fetchMemory*`） |
